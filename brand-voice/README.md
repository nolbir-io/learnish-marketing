# brand-voice

How Learnish sounds — to parents and to kids, across languages, channels, and audiences — on the road to 1,000 families.

## Purpose

Define the voice once so every workshop flyer, app screen, email, landing page, and social post sounds like the same company. This folder owns the source-of-truth voice docs; every other folder (campaigns, content-creation, landing-pages, sales-enablement) borrows from it. The [brand-review](../brand-review/) folder owns the *check* that content matches this standard.

## The core tension

Learnish speaks to **two audiences at once**: **parents** (who buy and must trust us) and **kids 5–17** (who use it and must love it). Trust is the foundation; delight is what keeps the kid coming back. When they conflict, trust wins. Everything in this folder serves that balance.

## Files

- [`voice-guide.md`](voice-guide.md) — personality, principles, tone by audience and moment, words to use/avoid, naming, and on/off-voice examples. **Start here.**
- [`language-matrix.md`](language-matrix.md) — Uzbek / English / Russian by audience and channel, script policy, multilingual rules, and localization QA.

## How this connects

- **Built from:** [product marketing context](../.agents/product-marketing-context.md) and [operating principles](../docs/strategy/operating-principles.md) (LEGO craft + trust, Duolingo delight + habit, Disney family trust).
- **Feeds:** all marketing skills (`/copywriting`, `/cro`, `/social`, `/emails`, etc.) read the product context and should honor this voice.

## Decided

- **Languages:** three primaries, priority Uzbek → English → Russian; Uzbek leads first-touch; Latin Uzbek default. See [language matrix](language-matrix.md).
- **Mascot:** yes — a bee, working name **Nish** (kid-facing). See [voice guide](voice-guide.md).
- **Safe & trusted proof:** reviewed, age-appropriate content. **Messaging hero:** STEAM toys + weekend workshops.
