# content-creation

Drafts, outlines, and source files for everything Learnish publishes — workshop landing pages, social posts, emails, flyers, and partner decks.

## Purpose

Where copy gets written. Pulls voice from [`brand-voice/`](../brand-voice/), gets checked in [`brand-review/`](../brand-review/), gets shipped through [`campaigns/`](../campaigns/), and gets measured in [`performance-analytics/`](../performance-analytics/).

Everything reinforces the **workshop flywheel** — `workshop → free family signup → Digital Club → Full Club → referral → next workshop` — and leads with the two anchors from the [voice guide](../brand-voice/voice-guide.md):

- **Safe & trusted = reviewed, age-appropriate content** (the proof we lead with on safety).
- **Hero = STEAM toys + weekend workshops** (the tangible hook; the Learnish Club is the wrapper).

## Audience reminder (two at once)

We write for **parents (who buy)** and **kids 5–17 (who use)** at the same time. Trust is for the parent; delight is for the kid; when they pull apart, **trust wins**. **Nish, the Learnish bee, is kid-facing only** — keep Nish in the background in parent trust copy (safety, pricing, data).

## Key questions each piece answers

- What does the campaign phase actually need — a workshop landing page, a founding-family story, a referral post, a partner one-pager?
- Which pieces are evergreen (workshop landing page, "how it works", safety explainer) vs. timely (a session recap, a milestone, a seasonal workshop)?
- Languages per piece — UZ-lead first-touch, with EN source + RU translation per `brand-voice/language-matrix.md`.
- What's the repurposing chain — does one workshop become a reel, 3 social posts, a Telegram recap, and an email?

## Folder layout

```
content-creation/
  README.md                 # this file
  editorial-calendar.md     # what ships when, tied to the workshop schedule
  paid-ads/                 # small local workshop-promotion batches (community-led, not ad-led)
  social/                   # channel drafts: Instagram, Telegram, LinkedIn
```

## What goes here next

- `landing-pages/` — drafts live in the top-level [`landing-pages/`](../landing-pages/) folder ([workshop-signup.md](../landing-pages/workshop-signup.md) is the lead LP).
- `email/` — welcome/activation sequences (free account → Digital Club → Full Club) and post-workshop follow-ups.
- `telegram/` — per-district group templates, workshop invites, session recaps, referral asks (Telegram is primary parent comms).
- `social/instagram/`, `social/linkedin/` — channel-specific drafts and threads.

## Channel split (decided)

- **Telegram** — primary parent comms + community (per-district groups).
- **Instagram** — local awareness + real session proof (parent-facing + kid delight).
- **LinkedIn** — repurposed for **investors / partners / hiring**, not parents.

## Voice and proof rules

All copy clears `brand-voice/voice-guide.md`. No fabricated stats or testimonials. Numeric/price claims show as **intro pricing, being validated** (Phase 4 WTP) or are marked `[PROOF — to collect]`. Real session photos/quotes only, with consent.
