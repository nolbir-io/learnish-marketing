## Status options

- Planned · Running · Completed · Stopped · Scaled

## Rules

- No experiment starts without **one** primary metric and **one** success threshold.
- Every completed test ends with one decision: **scale, iterate, or stop**.
- When a result changes an assumption, update the [open questions register](../docs/playbook/open-questions-register.md).
- Pre-app, prefer experiments on the **live** surfaces (workshops, store, referral) — those are the only places we can read real behavior today.
