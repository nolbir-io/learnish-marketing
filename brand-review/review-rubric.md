# Brand Review Rubric

Scored checklist run before any Learnish marketing asset is published. It checks that content is **safe, on-voice, on-message, and correctly localized** for both audiences (parents who buy, kids who use). Depends on [`brand-voice/voice-guide.md`](../brand-voice/voice-guide.md) and [`brand-voice/language-matrix.md`](../brand-voice/language-matrix.md) as the standard.

## Scoring

- **2 = Pass** — ships as-is.
- **1 = Needs edits** — minor fixes before publish.
- **0 = Fail** — must revise and get a second review.

## Criteria

| Dimension | Score (0–2) | Notes |
|---|---|---|
| **Safety & trust** — nothing that undermines the "safe and trusted" promise; kids' wellbeing and data handled honestly; no claims we can't stand behind | | |
| **Voice consistency** with [`voice-guide.md`](../brand-voice/voice-guide.md) — reassuring, concrete, exciting-not-hyped, no banned words | | |
| **Dual-audience fit** — reassures the parent *and* appeals to the kid for the relevant age band (5–12 / 13–17); trust wins where they conflict | | |
| **Message clarity** — the right slice (app / workshop / Club / kit) is clear; ties to the family-account / free-workshop CTA | | |
| **Claim accuracy & proof** — value claims (e.g. "~$280+ bundled value"), pricing, and workshop details match the [monetization model](../pricing/monetization-model.md) and reality | | |
| **Localization quality** — UZ/RU (and EN where used) per the [language matrix](../brand-voice/language-matrix.md); localized not just translated; brand terms stable | | |
| **CTA clarity** — one clear next step, low-pressure where appropriate (come to a free workshop / create a free family account) | | |
| **Age-appropriateness & sensitivity** — tone, imagery, and consent suitable for content about/for children; real-kid imagery has consent | | |

## Approval rule

- **Minimum total: 13/16.**
- **Any zero on Safety & trust or Claim accuracy = automatic rework**, regardless of total.
- Any other zero requires rework and a second review.

## Reviewers

- **Voice / brand:** marketing lead.
- **Safety, claims & pricing:** founder (or DRI) for anything touching child safety, data, or money.
- **Localization:** native UZ/RU reviewer — ideally a parent for parent-facing copy.

See [governance RACI](../docs/playbook/governance-raci.md) for decision rights.
